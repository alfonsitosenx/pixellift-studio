# PixelLift Studio

Windows app by [Excess Pro Net LLC](https://excesspronet.com) that resizes whole folders of JPG, PNG and WebP images to as many sizes as you need, converts them to WebP and reduces their file size. Everything runs on your own PC.

**This repository hosts the downloads only. It contains no source code.**

## Download

**[Latest release](https://github.com/alfonsitosenx/pixellift-studio/releases/latest)**: `PixelLiftStudio-Setup-1.0.1.exe` (14.9 MB)

## Requirements

- Windows 10 or Windows 11, 64-bit
- About 250 MB of disk space. Setup offers drive D: when you have one, and you can choose any folder.
- Internet only for license activation. All image processing is local.

## Free plan and Pro

| | Free | Pro ($12/year) |
|---|---|---|
| Images per batch | Up to 10 | Unlimited |
| Scales | 20, 50, 80, 100% | Also 200, 300, 400% |
| Convert to WebP, reduce file size | Included | Included |

A Pro license activates on one computer at a time and can be released from inside the app and moved to another.
